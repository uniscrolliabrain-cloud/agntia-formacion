## Criterios para pasar de scaffold a READY
(1) inventario real de archivos y firmas; (2) matriz de dependencias; (3) patchsets concretos con create/modify/import/export/tests/rollback; (4) handoffs personalizados Freebuff/Codex/Architect+Founder; (5) gates negativos, seguridad multitenant, ADTC, evidencias; (6) decisión de alcance y aprobación. No suponer que las rutas de código propuestas existen.

## Nota de producto
Las 42 campañas originales se orientan a LMS/tutoría/evaluación. El founder también exige actualización semanal por empresa, newsletter y soft skills. Resolver prioridad y modificaciones al manifiesto mediante ADR antes de iniciar desarrollo, sin perder la documentación original.
